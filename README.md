# 🎓 UofR GPA Pro Simulator

A precise GPA calculation and planning tool for University of Regina students. It accurately simulates official academic policies including retake logic and the 0-55% grading rule.
https://uofr-gpa-pro-simulator.netlify.app/
## ✨ Key Features
- **Official Policy Engine**: Handles NP (55%), XF (0%), and the 0-55 logic.
- **Smart Retakes**: Automatically counts only the most recent course attempts.
- **Simulation Mode**: Add future courses to forecast your final UGPA.
- **Visual Distribution**: View grade trends with interactive charts.

## 🚀 Quick Start
```bash
npm install
npm run dev
```

## 🌐 Deployment
Pre-configured for **Netlify**. Connect your repository and it will build automatically using the `netlify.toml` settings.
